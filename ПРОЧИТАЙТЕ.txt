ЗАПУСК И ПЕРЕНОС
Это серверное приложение React/TypeScript + Vinext с Cloudflare D1/R2,
а не статический HTML-файл. Требуется Node.js версии из package.json
и менеджер pnpm версии из поля packageManager.

Установите зависимости: pnpm install --frozen-lockfile
Проверка кода: pnpm exec tsc --noEmit
Проверка бизнес-логики: node tests/core.mjs
Команды сборки и локального запуска находятся в package.json.

Исходный код сохранён без изменений. В .openai/hosting.json остаётся ID
действующего сайта: НЕ публикуйте туда изменения случайно при переносе
в новый проект. Создайте отдельный проект и его собственные настройки.

В новом окружении нужно подключить серверные ресурсы DB (D1) и BUCKET (R2),
применить миграции и импортировать data/kontakt.sql в ПУСТУЮ базу SQLite/D1.
Альтернативно используйте JSON для собственного мигратора.
Файлы JSON, SQLite и SQL содержат одну и ту же клиентскую базу.

Авторизация использует проверенную Sites-идентичность, а не собственные
пароли. При переносе на Vercel либо другой хостинг необходимо адаптировать
авторизацию и доступ к D1/R2; простая загрузка архива этого не заменит.
Идентификатор пользователя ChatGPT зависит от сайта. При переносе нужно
проверить соответствие учётных записей и сохранить историю авторов.

В текущем интерфейсе восстановление принимает копии из подключённого R2.
Внешний JSON-файл нельзя просто выбрать в этом интерфейсе без адаптации
импорта резервных копий. Для переноса предназначены приложенные SQL/SQLite.

ЗАЩИТА ДАННЫХ
Архив содержит реальные контакты. Каталог data/ нельзя публиковать в
открытом репозитории, размещать среди публичных файлов сайта или раздавать
посетителям. Он нужен только для защищённого переноса и хранения копии.
Ключи доступа, токены, пароли, node_modules и временные файлы в архив
не включены. Автоматическое расписание резервного копирования ранее
не было настроено; архив не означает, что оно теперь включено.
